2. Dimensions at Temperature

ΔL = α L0 (T − T0), L = L0 + ΔL1,2. The same strain applies to X and Y, so a part keeps its proportions; area grows by roughly 2αΔT1.

3. Material A vs Material B

Size difference is B − A at that temperature. Differential growth is how much more B has changed than A since T0 — for the same nominal size, a positive value means B grows away from A (a B bore loosens round an A shaft; a B shaft tightens in an A bore).

Coefficients available mean linear CTE by type and grade, from the shared library

Values are the library's quoted figures (typically near room temperature up to a few hundred °C) and are applied as constants. Library data sources are cited per grade on the Material Library page.

Limits of this method

α normally rises with temperature, so a single mean value is a good estimate over modest temperature spans and degrades for large ΔT1,2. For wide ranges, use a coefficient measured over the actual span (dilatometer data, e.g. ASTM E228) or step through smaller ranges. Also not covered: anisotropic materials, phase changes, and restrained expansion (thermal stress).

Applicable design standards

  • ASTM E228 — Standard Test Method for Linear Thermal Expansion of Solid Materials With a Push-Rod Dilatometer (how metal CTE data is measured).
  • ISO 11359-2 — Plastics — Thermomechanical analysis (TMA) — Part 2: Determination of coefficient of linear thermal expansion and glass transition temperature (for polymers; none are in the shared library yet).

This page applies a simple constant-coefficient relation; it does not reproduce either test standard. Conformance-critical work should refer to the standards and to measured data for the actual material.
