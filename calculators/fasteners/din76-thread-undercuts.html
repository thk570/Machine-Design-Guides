Thread run-out relief ("undercut") for a metric ISO thread that must be chased right up to a shoulder, so the last few incomplete threads don't foul assembly. DIN 76-1 defines four relief forms: Form A/B for an external thread (bolt, screw, shaft end) and Form C/D for an internal thread (tapped hole) — each with a standard-length and a short variant. The diagrams below are traced from a reference drawing of the four forms; the dimensions are looked up directly from DIN 76-1's own pitch-indexed table (min/max groove length, undercut diameter and corner radius per pitch — see the note in section 3 and the footer) rather than computed from a formula.

Applicable design standards

  • DIN 76-1 — Thread run-outs and thread undercuts — Part 1: For ISO metric threads in accordance with DIN 13-1 (the governing standard; this page's Table 1/Table 2 values are transcribed from it per pitch — see the reference below for provenance).
  • ISO 13-1 / DIN 13-1 — ISO general purpose metric screw threads — basic profile and dimensions (defines the nominal diameter d and pitch P used to key the lookup).
  • ISO 261 — ISO general purpose metric screw threads — general plan (the standard coarse/fine pitch series used for the size dropdown, same series as the Screw Torques page).

Values are keyed on pitch, exactly as DIN 76-1 tabulates them — always confirm against the current edition of the standard before this drives a released drawing.
