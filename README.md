# Machine Design Guides

Static suite of machine-design reference tools and calculators (fits, fasteners, seals, electrical, materials).
Open `index.html` locally, or use the GitHub Pages site. Deployed automatically by
`.github/workflows/pages.yml` on every push to `main` (Settings → Pages → Source: **GitHub Actions**).

See `docs/structure-and-conventions.md` for how to add a page.
